# TECO public solar buildings

Site facts: [PanelCensus TECO public search](https://panelcensus.com/sites?operator=Tampa%20Electric%20Co); individual source URLs are retained. Missing sizes use base yellow.

Footprints come exclusively from the existing local OSM Buildings layer (`data/osm/tampa-bay/buildings.geojson`), and only public solar sites within its manifest coverage are included. See the OSM layer NOTICE and manifest for source provenance. Building geometry © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), [copyright](https://www.openstreetmap.org/copyright).

Each site is assigned to the nearest footprint in that complete local layer. Equal distances within 0.01 metres select the larger footprint. Building associations are spatial matches, not verification of rooftop PV. Multiple records on a building use the largest reported size and retain every source record. No circle symbols are drawn.
