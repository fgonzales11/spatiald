# TECO PKL PV display layer

Source: the verified 63-model TECO extraction in data/solar/teco-models/teco-asymmetric-sgen.json. All asymmetric_sgen devices were included following the user’s clarification because model names contain no PV identifiers. Technology is unclassified in the models. Phase rows represent one device, not separate PV installations. Bus coordinates determine the nearest local OSM building. Model active power is operating generation, not installed PV capacity.

Footprints are from data/osm/tampa-bay/buildings.geojson, © OpenStreetMap contributors, ODbL 1.0. Only records within the local OSM manifest coverage are included. Equal-distance matches use the larger footprint. Geographic association does not independently verify rooftop PV. The layer draws red building fills only.
